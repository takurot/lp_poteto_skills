Self-hosted web fonts (SPEC section 4 and 7). All three families are licensed under the
SIL Open Font License 1.1; the license text for each family is in the OFL-*.txt file next
to its fonts.

Files are copied unchanged from the Fontsource npm packages, which build their woff2 files
from the Google Fonts repository (https://github.com/google/fonts). Only the "latin" subset
of each used weight is included. Japanese text uses the system CJK fonts listed in style.css.
